# jingtun (Whale Swallow)：界面与使用指南

> 本指南对应 v1.0.0。界面语言跟随浏览器：中文环境显示「鲸吞」，其他语言显示「Whale Swallow」。
>
> 想直接看界面长什么样，打开仓库里的 `tools/preview/index.html`（由 `node tools/make-preview.js`
> 生成，内嵌了桩数据，用普通浏览器打开即可，不需要加载扩展）。

### 3. 其他页面

- **preview.html**：播放器，可切换画质预览、验证密钥是否正确。
- **options.html**：设置页，分组包含嗅探、下载、推送、判定规则、界面等。
- **manage.html**：跨标签页资源汇总，筛选/搜索/批量操作。
- **downloader.html**：手动粘贴地址或 JSON 批量下载。
- **json.html**：查看嗅探到的接口 JSON。

## 二、核心使用逻辑（决策树）

### 场景 1：页面上有直链 mp4 / webm / m4a

1. 打开页面，播放几秒（让请求发生）。
2. 点扩展图标 → 资源列表按时间出现。
3. 找到目标 → 点 **下载**（或右键菜单/批量下载）。
4. 直链走 `chrome.downloads`，带 Referer/Origin 等防盗链头。

### 场景 2：HLS（m3u8）点播

1. 列表里出现 `.m3u8` → 点 **播放** 先在内置播放器里确认画质。
2. 点 **下载** → 打开详情面板或解析页。
3. 主播放列表会先让你**选画质**（默认最高码率）。
4. 在下载区设置并发（默认 4）、是否跳过解密、手填密钥（可选）。
5. 点 **开始下载**：
   - 分片并行下载，慢启动 + 限流感知自动调并发；
   - AES-128 自动解密；
   - TS 会自动用本地 ffmpeg 转封装成 MP4（失败则保留原始 TS）；
   - 已下载分片写入磁盘缓存，中断后重跑只补缺的。
6. DASH（mpd）走同样流程；音视频分轨时用 **合并下载** 一次下完并合成。

### 场景 3：直播（m3u8 无 ENDLIST）

1. 下载按钮会变成 **录制直播**，并提示目标时长。
2. 点它 → 扩展跟随清单刷新，边收边下。
3. 想结束时点 **停止**，扩展把收到的分片合并导出。
4. 因为跟不上而丢失的分片会在结果里明确报数。
5. 也可以在调用处用 `maxDuration` / `maxSegments` 设上限（设置页暂无开关）。

### 场景 4：页面用 blob: 播放（MSE）

1. 列表里出现 `blob:` 地址，或页面有 DRM 提示。
2. 点 **捕获** → 从头播放视频。
3. 扩展代理 `MediaSource.addSourceBuffer`，把数据缓存下来。
4. 播完（或够长）后点 **导出**，扩展清理重复容器头、补初始化段后保存。
5. 音视频双轨会分别导出，并给出 ffmpeg 合并命令。

### 场景 5：直链直播 / WASM 播放器 / WebRTC

- **录制**：`⋯` → 录制，用 `captureStream + MediaRecorder` 实时录。画质有损、耗时等于播放时长。
- **WebRTC**：`⋯` → WebRTC，从轨道层捕获，会刷新页面。
- **区域录制**：`⋯` → 区域录制，只录页面某块，需授权屏幕共享。
- **手机 UA**：`⋯` → 手机 UA，临时切移动端 UA 并刷新，有些站点只在移动端给直链。

### 场景 6：列表为空 / 找不到地址

1. 点 **深度搜索**：注入 hook（fetch / XHR / JSON.parse，含 Worker），刷新页面。
2. 从接口响应里递归找出藏起来的媒体地址。
3. 常开深度搜索有性能开销，默认关闭（设置页可开）。

## 三、v1.0.0 的稳健性逻辑（用户视角）

| 现象 | 扩展现在的行为 |
|---|---|
| 并发开多了，服务器开始返回 403/429 | 自动把并发减半、冷却后重试，并慢速恢复 |
| 防盗链站点，浏览器能播但分片 403 | 分片请求带上源页面 Referer（`fetch.referrer`） |
| 下载中途失败 / 关了页面 | 磁盘断点续传：重跑只补缺失分片 |
| 某个请求卡住不动 | 单次请求超时（默认 30 秒）后重试 |
| 服务器忽略 Range 请求 | 判定为错误，不再拼出损坏文件 |
| 密钥接口拿不到密钥 | 用页面里捕获到的真密钥兜底 |
| 手填了解密密钥 | 优先用你填的，不再盲目去请求 URI |
| SAMPLE-AES / DRM / 差分清单 / I 帧清单 | 明确提示「下不了 / 会缺头」，不给你一个坏文件 |

## 四、快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt + C` | 开始 / 停止流媒体捕获 |
| `Alt + S` | 对当前页面执行深度搜索 |
| `Alt + E` | 启用 / 停用嗅探 |
| `Alt + X` | 清空当前标签页的资源列表 |

`preview`、`auto-down` 等命令没有默认按键，可在 `chrome://extensions/shortcuts` 自行分配。

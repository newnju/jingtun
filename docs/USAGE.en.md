# Whale Swallow: UI and usage

> This guide covers v1.0.0. The UI follows your browser language: Chinese setups show 鲸吞, others show "Whale Swallow".
>
> To see what the UI looks like, open `tools/preview/index.html` in the repo (generated by `node tools/make-preview.js`, with stub data baked in). No extension load needed.

---

## 1. The popup

Click the toolbar icon.

```
+------------------------------------------------------------------+
| [icon] Whale Swallow  [0]                      toggle   ...     |
+------------------------------------------------------------------+
| (DRM banner, only when detected)                                 |
| (Captured-key banner, only when detected)                        |
+------------------------------------------------------------------+
| [This tab] [Other tabs]   [ filter by regex ]                    |
| [Deep search] [Capture] [Export (after capture)]                 |
+------------------------------------------------------------------+
| ... menu contents:                                               |
|   Record: Record / WebRTC / Region / Mobile UA                   |
|   List: Expand all / Collapse / Drop duplicates                  |
|   Pages: M3U8 / MPD / Downloader / Manager / New window /        |
|          Guide / Settings                                        |
|   Clear list                                                     |
+------------------------------------------------------------------+
| (batch bar, appears when items are selected)                     |
| (media controls, only when a <video> element exists)             |
+------------------------------------------------------------------+
| Resource list                                                    |
|   video.mp4   186 MB    [play] [download]                        |
|   master.m3u8   4 KB    [play] [download]                        |
+------------------------------------------------------------------+
```

Only the two actions that set this extension apart — **Deep search** and **Capture** — stay on the main bar. Everything else lives behind `...`. The batch bar and media controls only appear when they are relevant.

## 3. The other pages

- **preview.html** - player, switch quality to preview, verify a key works.
- **options.html** - settings: sniffing, downloads, push, classification rules, UI.
- **manage.html** - resources across all tabs, with filtering, search and batch actions.
- **downloader.html** - paste a URL or a JSON list to download in bulk.
- **json.html** - inspect the JSON behind a captured API response.

## 4. Common tasks

### A direct link (mp4 / webm / m4a)

1. Open the page and play for a few seconds so the request fires.
2. Click the extension icon; the resource shows up in the list.
3. Click **Download** (or use the context menu / batch download).
4. Direct links go through `chrome.downloads`, with Referer and Origin attached.

### HLS (m3u8) on demand

1. When a `.m3u8` appears, hit **Play** first to confirm the quality.
2. Click **Download** to open the detail panel or the parser page.
3. For a master playlist you pick a quality first (highest is preselected).
4. Set the thread count (default 4), whether to skip decryption, and optionally paste a key.
5. Click **Start download**:
   - segments download in parallel, with slow start and throttle-aware concurrency;
   - AES-128 is decrypted automatically;
   - TS is remuxed to MP4 with the bundled ffmpeg (falls back to the raw TS if that fails);
   - finished segments go to the disk cache, so an interrupted run only refetches the missing ones.
6. DASH (mpd) follows the same path; for split audio/video use **Merge**.

### Live (m3u8 without ENDLIST)

1. The download button becomes **Record live** and shows the target duration.
2. Click it; the extension follows the playlist and downloads as it goes.
3. Press **Stop** to finish and export what was captured.
4. Segments lost because the download fell behind are reported explicitly.
5. You can also cap it with `maxDuration` / `maxSegments` programmatically (no UI switch yet).

### Blob playback (MSE)

1. A `blob:` URL shows up, or the page shows a DRM warning.
2. Click **Capture**, then play the video from the start.
3. The extension proxies `MediaSource.addSourceBuffer` and keeps the data.
4. When you have enough, click **Export**: it cleans duplicate container headers, restores the init segment and saves.
5. If there are two tracks, both files are exported along with the ffmpeg merge command.

### Direct-link live / WASM players / WebRTC

- **Record**: `...` -> Record, using `captureStream + MediaRecorder`. Lossy, and takes as long as the playback.
- **WebRTC**: `...` -> WebRTC, captures from the track level; reloads the page.
- **Region**: `...` -> Region, records only part of the page; needs screen-share permission.
- **Mobile UA**: `...` -> Mobile UA, switches to a mobile user agent and reloads; some sites only serve direct links on mobile.

### Nothing in the list

1. Click **Deep search**: inject hooks (fetch / XHR / JSON.parse, including Workers) and reload.
2. Media URLs hidden inside API responses are extracted recursively.
3. Keeping deep search always on has a performance cost, so it is off by default (enable it in settings).

## 5. What changed in v1.0.0 (from a user's point of view)

| Symptom | What the extension does now |
|---|---|
| More parallelism, more 403/429 from the server | Halves concurrency, cools down, then retries and recovers slowly |
| Hotlink-protected site plays in the browser but segments 403 | Segment requests carry the source page as Referer (`fetch.referrer`) |
| Download fails or the page is closed | Disk resume: a rerun only fetches the missing segments |
| A request hangs | Per-request timeout (30s by default), then retry |
| Server ignores Range requests | Treated as an error; no more silently corrupted files |
| Key endpoint returns nothing | Falls back to a key captured from the page |
| You pasted a decryption key | It is used, instead of blindly requesting the URI |
| SAMPLE-AES / DRM / delta playlist / I-frame playlist | Explained clearly; no broken file is produced |

## 6. Shortcuts

| Shortcut | Action |
|---|---|
| `Alt + C` | Start / stop streaming capture |
| `Alt + S` | Deep search on the current page |
| `Alt + E` | Enable / disable sniffing |
| `Alt + X` | Clear the resource list for the current tab |

`preview` and `auto-down` have no default binding; assign them in `chrome://extensions/shortcuts`.

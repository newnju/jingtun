鲸吞

媒体资源嗅探与下载扩展

基本

启用嗅探 关闭后不再记录任何媒体请求
在图标上显示数量 把当前标签页的媒体数量显示在扩展图标角标上
最新资源排在最前 默认按捕获顺序排列，开启后倒序显示
配置跨设备同步 通过浏览器的账号同步把设置带到其他设备。 本地始终保存一份，同步只是分发渠道， 判定表这类内容较大时可能超出同步配额，那时只保留本地

嗅探

按 MIME 类型判定 优先看响应头的 Content-Type。关闭后只认扩展名，可能漏掉无扩展名的流地址
同一地址只记录一次 关闭后同一地址会重复出现在列表里。只有极少数场景需要关掉
每个标签页最多记录 超出后自动淘汰最早的记录。调大可保留更长的历史，但更占内存
体积下限（KB） 小于此值的资源不计入列表，用来挡掉试看片段、占位音频这类噪音。 填 0 表示不过滤。响应头没给大小的一律放行
屏蔽域名 每行一条。支持通配子域，例如 *.example.com 会同时屏蔽 a.example.com 与 example.com
URL 改写规则 每行一条正则，需含一个捕获组。命中时把捕获组的内容当作真实地址。 用来对付播放地址藏在跳转参数里的站点，例如 player\?src=([^&]+) 能从 /player?src=https%3A%2F%2Fcdn%2Fv.mp4 里挖出真实地址。 捕获组的内容若以 http 开头才会被采用
后缀判定表 每行一条，逗号分隔：扩展名, 操作符, 大小, 单位。 只有扩展名必填，例如 mp4；要加体积条件就写 mp4, >, 1, MB（只收大于 1MB 的）。 支持 > >= < <= = !=，单位 B/KB/MB/GB。 留空表示用内置默认规则
MIME 判定表 格式同上，第一列换成 MIME 类型。用来兜住没有扩展名的地址， 例如 video/mp4，或 application/octet-stream, >, 1, MB
正则判定表 每行 正则, 扩展名。地址长得不像媒体但确实是时用它补充判定， 比如 /play?id=123 这种没有任何扩展名的接口地址。 第三列写 black 表示黑名单（命中即排除）
测试正则 拿一个真实地址试试上面的规则，看会不会命中、补出什么扩展名

界面与体验

用侧边栏代替弹窗 侧边栏常驻窗口右侧，不会被别的操作挤掉。 边看视频边挑资源时比弹窗舒服，改完需重新加载扩展
列表显示网站图标 每项前面显示来源站点的 favicon，快速区分多个来源
自动配组音视频 把时间邻近的音视频自动配成一组，方便一起下载
配组时间差（秒） 两次捕获间隔在此之内才算同一组
自动清理 什么时候清理已捕获的数据
屏蔽网址按白名单用 默认黑名单（名单内的不嗅探）；打开后反过来， 只有名单内的站点才嗅探
标题规则 列表里标题怎么显示，留空用页面标题。 可用 ${title} / ${name} / ${host} / ${ext}
下载前询问文件名 自动生成的名字常是一串 hash，开这个会在下载前让你改一次
启用右键菜单 默认关闭。装了一堆扩展后右键栏本来就长， 再挂一个「鲸吞」子菜单只是噪音， 弹窗里能做的事，没必要在右键里再来一遍
自定义 CSS 注入到网页（不是扩展界面），用于隐藏遮挡元素、 适配移动端布局等。注入脚本时才生效

推送到本地服务

嗅探到新资源时，把信息发给你自己跑的程序（下载器、媒体库等）。 失败只记录日志，不会影响嗅探和下载。

启用推送 关闭后不再发送任何请求
服务地址 例如 http://127.0.0.1:6800/jsonrpc
请求方法 GET 时参数会拼在地址后面，没有请求体
请求体模板 留空则整个发 JSON。可用 ${url} / ${name} / ${ext} / ${title} / ${pageUrl} / ${referer} / ${size}
额外请求头 每行一条 Name: value

MQTT 推送

把嗅探到的资源推到 MQTT broker，给 Home Assistant、 Node-RED 这类自动化工具用。浏览器只能走 WebSocket， 所以端口要填 ws/wss 的（Mosquitto 常见 8083 / 8084）。

下载路径学习

有些站点的防盗链是常态（浏览器下载必然 403）。 扩展会记下每个域名的成功 / 失败次数， 连续失败过又从来没成功过的，下次直接走页面身份重试， 省掉一次注定失败的尝试。

深度搜索与捕获

常开深度搜索 打开每个页面时自动注入 hook，主动探测接口里的媒体地址。 有明显性能开销，一般建议保持关闭，需要时在弹窗里手动点一次
捕获后自动合并音视频 MSE 里音视频是两个独立的轨道，默认会导出 「有画无声 + 有声无画」两个文件。 开启后交给本地 ffmpeg 合成一个完整的视频。 数据要经消息传给转码环境，超大体积建议保持关闭
外部播放器 浏览器对 HEVC、部分 4K、特殊音频格式支持不全， 放不了时可以交给本地播放器（需已安装）
捕获时自动跳缓冲尾 数据靠播放器缓冲下来的，得播完整片才能捕全。 开着它会替你自动拖进度条，大幅缩短等待。 注意：它会改变播放进度，不想被打断就别开
捕获完成自动导出 检测到流结束（播放器播完）就自动保存。 长视频不用一直守着
移除 iframe sandbox 限制 少数站点把播放器放在 sandbox iframe 里，导致脚本注入不进去、 什么都捕获不到。打开这个可以解决， 但会放宽页面的安全限制，只在确实需要时开
下载后移出列表 下载成功的条目自动从列表移除。 有分片失败的会保留，方便重试
捕获内存上限（MB） MSE 捕获的数据先放在内存，超过此值自动落盘并停止累积，避免页面卡死
用移动端 UA 请求 有些站点的资源只在移动端下发，桌面 UA 拿到的页面里根本没有播放器。 开启后请求会带 iPhone 的 User-Agent。 页面会按移动端渲染，布局会变，所以默认关闭

下载

文件名模板 可用变量：${title} 页面标题、${name} 原始文件名、 ${ext} 扩展名、${index} 序号、${date} 日期。 也支持 ${ext|upper} 这类过滤器
模板预览 —
用真实地址试一下 粘一个地址，看文件名模板在它身上会渲染出什么
复制模板 点「复制」时写进剪贴板的内容。默认只复制地址； 防盗链站点可以带上 Referer，例如 ${url} ${referer|exists:'-H "Referer:*"'}， 粘到命令行就能直接用
N_m3u8DL-RE 参数 只填参数，程序名会自动补上。支持条件展开： ${referer|exists:'-H "Referer:*"'} 有 Referer 才加，没有就整段消失
ffmpeg 参数 同样只填参数。默认模板会把 HLS 转存成 mp4
自动下载 嗅探到匹配资源时立即开始下载。慎用，页面上的广告素材也可能被一并下载
下载子目录 留空则使用浏览器默认下载目录。不支持绝对路径
使用 aria2 下载 大文件走 aria2 明显更快，且支持断点续传。 aria2 启动时要加 --enable-rpc --rpc-allow-origin-all， 否则扩展连不上。失败会自动退回浏览器下载
aria2 RPC 地址 默认 http://127.0.0.1:6800/jsonrpc
aria2 RPC 令牌 启动时用 --rpc-secret=xxx 设置的密钥，没设就留空
aria2 保存目录 aria2 所在机器上的路径，留空用它的默认值

通知

检测到 DRM 时提示 页面调用 Widevine / PlayReady 等加密系统时给出提示。 加密内容在浏览器层面就无法导出明文，提示只是避免白费力气

维护

清空所有捕获记录 删除全部标签页已嗅探到的资源列表。只影响列表， 已经下载到本地的文件不受影响。设置项不会被重置
